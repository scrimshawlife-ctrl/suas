What it is

Consent-governed peer coordination.

A veteran says what they need. They grant consent. We try to put a human or a material resource on that need.

  • Need

    The veteran names a need. MVP categories: FOOD, TRANSPORTATION, SHELTER, PEER_SUPPORT.

  • Consent Grant

    Disclosure waits on a Consent Grant. Membership in a trusted circle is not a permission.

  • Coordination

    We try to match a consented human or a material resource. Manual coordination remains valid where a live provider is unavailable.

What it is not

Not a clinic. Not a launch.

  • Not an EHR

    SUAS does not store a medical record or stand in for clinical systems.

  • Not a diagnosis

    A Check-In is not a diagnosis. A Support Signal is not a clinical score.

  • Not a suicide predictor

    SUAS does not predict suicide and does not run safety-critical generative scoring.

  • Not 911

    SUAS does not call 911. There is no automated emergency dispatch.

Real versus not

What the API can do today.

This is the implementation kernel, not this Pages tab. Pages does not call Fastify, Neon, or Workers.

On the API today

  • Passwordless challenge and session
  • Check-In start, answer, complete (qv-001 scores)
  • Support Case read and claim
  • Consent Grant grant and revoke
  • Resources and veteran status
  • Follow-Ups
  • Notifications: in-app, fake or sink only
  • QRF deploy and cancel

Not wired

  • Join persist
  • Live Uber, rooms, food, or peer APIs
  • 911 or any automated emergency dispatch
  • A public /app host on this Pages site

Formal synthetic STAGING exists for owner-controlled evidence. It is not this URL, and it is not authorization for real veteran data.
